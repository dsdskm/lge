이슈 토큰 사용량 & 비용

2-Stage 파이프라인(Stage1 분류 → Stage2 분석)이 로봇 이슈 1건을 처리할 때 소비하는 토큰량과 비용 추정

기준 모델: Azure OpenAI · GPT-4.1 (2025년 현행 단가 기준) — 입력 $2.00 / 1M tok, 출력 $8.00 / 1M tok · 환율 1,380원/$ 기준. 단순 분류를 GPT-4.1-mini($0.40/$1.60)로 라우팅하면 비용이 약 80% 낮아집니다.

처리 단계 주요 입력 컨텍스트 입력 토큰 출력 토큰
